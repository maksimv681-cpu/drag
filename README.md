# Шашки 3D

Аркадная 3D-гонка в браузере: лавируй в плотном потоке на трассе и проходи как можно ближе к машинам.

Чтобы поиграть, откройте `index.html` в браузере. Сервер и сборка не нужны: three.js лежит в `game/vendor`.
Если удобнее через сервер: `python3 -m http.server` и затем http://localhost:8000.

**На телефоне** используйте `shashki3d.html` — это вся игра в одном файле. Скачайте его (на GitHub: файл → «Download raw file») и откройте в Chrome или Safari.
`index.html` без папки `game/` не работает.
После изменений в `game/` пересоберите этот файл: `node tools/build-single.mjs`.

## Очки

- Очки идут за пройденный путь; выше 120 км/ч — быстрее.
- «Шашка» — обгон на скорости от 90 км/ч, когда между бортами меньше 1,2 м: +120 очков. Если ближе 0,5 м — «Впритирку!», +250.
- Шашки подряд (с интервалом до 3,5 с) дают множитель комбо до ×10 и заполняют нитро.
- Поток становится плотнее с каждым километром. Машины включают поворотник перед перестроением.
- Рекорд сохраняется в браузере.

## Файлы

- `index.html` — разметка и интерфейс
- `game/game.js` — игра (сцена, трафик, физика, звук на WebAudio)
- `game/style.css` — стили интерфейса
- `game/vendor/three.min.js` — three.js r159 (лицензия MIT, `game/vendor/three.LICENSE`)
